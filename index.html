API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「送給 AI 生成」時，組成後的提示詞會直接傳送給你選擇的服務商 API。請勿在共用電腦上填寫金鑰。

REC已儲存的提示詞

把目前這份提示詞（含 AI 產生結果，若有）存成一筆有名字的紀錄，留在這台瀏覽器裡；需要檔案再從清單裡個別下載。

使用警語
  • 本工具產生的是「提示詞架構」與 AI 生成內容，請自行檢查是否符合你所使用之 AI 服務的條款與政策。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容——欄位資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器，但送出給 AI 服務後的隱私仍由該服務條款規範。
  • 「送給 AI 直接生成」需要你自行填入 API 金鑰，該金鑰只存在你的瀏覽器，按下產生時會直接連線到你選擇的服務商，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • AI 生成內容可能有誤，使用前請自行查證；本工具與創作者不對後續 AI 輸出結果負責。
