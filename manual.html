操作手冊

AI 提示詞產生器提供四種提示詞框架：專為「AI 影音工坊」設計的逐段腳本框架，以及 TAG／APE／CO-STAR 三種通用提示詞框架。填入變數即可組成結構完整的提示詞，也可以直接串接你自己的語言模型一鍵取得 AI 產生的內容。

四種框架各自適合什麼情境

影音
AI 影音工坊框架

填「主題／幾段／補充說明」，組成的提示詞會要求 AI 產出逐行的「中文旁白｜英文搜尋關鍵字」腳本，格式與 ai-video-studio「01 腳本」欄位的解析規則完全對應，AI 產生的結果可以直接複製貼過去用。

TAG
TAG 框架（Task／Action／Goal）

把「要做什麼任務、具體怎麼做、最終想達成什麼目標」講清楚，適合交辦型的單一任務，例如寫一封信、一則通知。

APE
APE 框架（Action／Purpose／Expectation）

把「要做的事、為什麼要做、期待的輸出長什麼樣子」講清楚，比 TAG 更聚焦在「輸出規格」上，適合明確、可執行的單一請求。

CO-STAR
CO-STAR 框架

Context 背景、Objective 目標、Style 風格、Tone 語氣、Audience 受眾、Response 輸出格式——六個維度最完整，適合需要精準控制文字風格與格式的內容產出，例如社群文案、公開回覆。

操作步驟

  1. 在最上方選一個框架分頁（影音工坊／TAG／APE／CO-STAR）
  2. 先套用一個「範例」快速看懂每個欄位該填什麼，或直接從空白開始填寫
  3. 按「🔧 組成提示詞」，下方會出現組成後的完整提示詞文字，可按「複製提示詞」貼到任何 AI 對話框自行使用
  4. 若想直接在本工具取得 AI 產生的內容，展開「送給 AI 直接生成」面板的「API 連線設定」填入自己的金鑰，按「🚀 送給 AI 直接生成」（見下方說明）
  5. 滿意的結果可以在下方「已儲存的提示詞」取名儲存，之後隨時載回來或下載成 .txt 檔
切換框架分頁不會清掉其他框架已填的內容——四個框架的欄位、組成結果與 AI 結果各自獨立保留在這台瀏覽器裡。

影音工坊框架的輸出格式規則

這個框架組成的提示詞，會要求 AI 嚴格依照以下規則輸出，才能跟 ai-video-studio 的腳本解析邏輯相容：

  • 一行一段，每行格式固定為「中文旁白文字｜英文Pexels搜尋關鍵字」，中間用一個半形 | 分隔
  • 每行只能有一個 |，不能有多餘的分隔符號
  • 不能有空行、不能有行號，也不能有除了指定行數以外的其他文字
拿到 AI 產生的結果後，直接複製整段貼進 ai-video-studio「01 腳本」欄位即可；若 AI 沒有完全照格式輸出，可自行手動修正後再貼上。

已儲存的提示詞

「已儲存的提示詞」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前這個框架已組成的提示詞（連同 AI 產生結果，若有）存成一筆有名字的紀錄。

  1. 在儲存名稱欄位打一個好記的名字（留白會自動取名），按「儲存」
  2. 清單中每一筆紀錄可以「載入」（會自動切換回對應的框架分頁並覆蓋欄位）、「複製」、「下載 .txt」或「刪除」
  3. 取相同名字再按一次「儲存」會詢問是否要覆蓋既有紀錄
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

送給 AI 直接生成（選用，需自備 API 金鑰）

組成提示詞之後，可以直接在本工具呼叫你自己的語言模型 API，取得 AI 實際產生的內容，不用再手動複製貼到別的地方。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. 按「🚀 送給 AI 直接生成」——若還沒按過「組成提示詞」，會自動先組成一次（前提是欄位都已填寫完整）
  3. AI 產生的結果會顯示在「AI 產生結果」區塊，可按「複製 AI 結果」使用
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

🔑 授權序號

本工具需先輸入授權序號並按「確認」驗證通過，才能使用整個工具（不是只鎖某個功能）。序號自第一次驗證起提供 12 個月使用期限，驗證結果每次開啟頁面都會即時向授權伺服器重新確認，並每 20 分鐘在背景重新驗證一次——序號到期時，畫面會在最多 20 分鐘內自動重新鎖定。

  • 序號輸入一次後會記在這台瀏覽器裡，下次開啟不用重新輸入（除非已逾期）
  • 「無法連線授權伺服器」：請先檢查網路連線；若持續發生，可能是授權伺服器尚未設定完成，請聯繫工具提供者

隱私說明

  • 你填寫的欄位內容、組成的提示詞與「已儲存的提示詞」清單都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • 複製提示詞後，貼到哪個 AI 服務、該服務如何處理這些文字，就依該服務自己的隱私政策規範，與本工具無關
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「送給 AI 直接生成」時，組成的提示詞會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

使用警語

請注意：
  • 本工具的核心功能是把你的想法組織成結構化提示詞；只有你主動填入 API 金鑰並按下「送給 AI 直接生成」時才會呼叫語言模型，不使用這項功能也能取得組成後的提示詞文字
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
